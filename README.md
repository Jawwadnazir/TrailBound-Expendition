# TrailBound Expeditions

A clean, responsive landing page for an outdoor hiking and guided expedition company. Built from scratch to practice semantic layout, responsive styling, and modern web design principles.

🌐 **Live Demo:** [trailbound-expendition.netlify.app](https://trailbound-expendition.netlify.app/)

---

## 🛠 Built With

- **HTML5:** Semantic markup (`<header>`, `<nav>`, `<section>`, `<footer>`)
- **CSS3:** Flexbox, CSS Grid, and media queries for responsive layouts

## ✨ Key Features

- **Fully Responsive:** Adapts seamlessly to mobile, tablet, and desktop screens
- **Clean Navigation:** Modern hero section and structured expedition highlights
- **Optimized Assets:** Structured project directory for clean code maintenance
